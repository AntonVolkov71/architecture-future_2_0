## Create SSH-key
- создать ключ
  - `ssh-keygen -t ed25519`
  - согласиться с предложением без уговоров
  - ввести фразу очень секретную
  - ключ по умолчанию создаться в каталоге:
    - `~/.ssh/id_ed25519.pub`


- скопировать открытую часть ключа (windows)
  - шаблон `type <путь_к_файлу_ключа>\<имя_ключа>.pub | clip`
  - `type C:\Users\volko\.ssh\id_ed25519.pub | clip`
