### TCO на 3 года

- входные параметры
    - 100 ТБ данных
    - 50 сервисов
    - 200 пользователей BI
    - Cloud: Yandex / AWS аналог


- AS-IS (legacy)
    - Ключевой фактор стоимости
        - Основной драйвер затрат в legacy архитектуре — лицензии SQL Server Enterprise.
        - При росте объема данных (100+ ТБ):
            - требуется масштабирование по ядрам
            - лицензирование растет линейно
            - стоимость становится непропорционально высокой

| Статья                   | Год (рублей)         |
|--------------------------|----------------------|
| SQL Server 2022 лицензии | 8-9 млн              |
| On-prem железо           | 6-7 млн              |
| Поддержка (команда)      | 12-15 млн            |
| BI кастомизация          | 3-4 млн              |
| **Итого**                | **~29-35 млн / год** |

- TO-BE
    - переезд в cloud + data mesh
        - масштабируется по факту потребления
        - не требует дорогих лицензий

| Статья                    | Год (рублей)     |
|---------------------------|------------------|
| Cloud (compute + storage) | 3,5 - 4 млн      |
| Kafka / streaming         | 0,3 - 0,5 млн    |
| Data platform             | ~2 млн           |
| Поддержка                 | 12-14 млн        |
| **Итого**                 | **~17-20 / год** |

- Вывод
    - снижение затрат: ~35–45%
    - основной эффект: отказ от лицензий SQL Server
    - уменьшение затрат на инфраструктуру
    - ускорение time-to-market
    - снижение стоимости аналитики (~30–40%)
