## Каталог доменных событий

- взаимодействие между доменами планируем через event driven communication

| Event                         | Domain    | Описание                           |
|-------------------------------|-----------|------------------------------------|
| PatientRegistered             | Patient   | зарегистрирован новый пациент      |
| PatientProfileUpdated         | Patient   | обновлены данные пациента          |
| MedicalStudyCompleted         | Clinical  | завершено медицинское исследование |
| DiagnosisGenerated            | Clinical  | сформирован диагноз AI системой    |
| InvoiceCreated                | Fintech   | создан счет                        |
| PaymentCompleted              | Fintech   | платеж успешно завершен            |
| CreditIssued                  | Fintech   | выдан кредит                       |
| EquipmentRegistered           | Inventory | зарегистрировано оборудование      |
| EquipmentMaintenanceScheduled | Inventory | запланировано обслуживание         |
